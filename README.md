# 🚀 СжатьФото.онлайн (CompressPhoto.online)

Современный, минималистичный и высокопроизводительный веб-сервис для **сжатия и конвертации фотографий прямо в браузере клиента**. Сервис спроектирован с упором на максимальное привлечение органического SEO-трафика из **Яндекса и Google**, имеет мультиязычную архитектуру (RU/EN), раздел документации с плотной перелинковкой и полностью готов к мгновенному деплою на **GitHub → Vercel**.

---

## ✨ Ключевые преимущества и возможности

- **100% Client-Side обработка (Canvas API & OffscreenCanvas)**:
  - Фотографии обрабатываются локально на процессоре пользователя.
  - Ни один байт не отправляется на сервер — полная конфиденциальность паспортов, виз и личных фото.
  - Работает даже в офлайн-режиме после первой загрузки страницы.
- **Поддержка форматов нового поколения**:
  - Входные: `JPEG`, `JPG`, `PNG`, `WebP`, `AVIF`, `BMP`.
  - Выходные: `WebP` (экономия до 80%), `JPEG`, `PNG` (с сохранением альфа-прозрачности).
- **Умное сжатие и подгон под целевой вес**:
  - Слайдер качества (1–100%) с быстрыми пресетами (60%, 80%, 92%).
  - **Режим строгого лимита в КБ**: автоматический бинарный поиск качества и пропорций для сжатия строго до **100 КБ / 200 КБ** (для портала Госуслуг, анкет на загранпаспорт, резюме и визовых центров).
  - Масштабирование геометрического разрешения (ресайз).
- **UX и интерактивность**:
  - Drag & Drop зона.
  - Вставка из буфера обмена (`Ctrl+V`) для моментальной оптимизации скриншотов.
  - Интерактивный сплит-слайдер сравнения качества **«До / После»**.
  - Пакетное скачивание всех обработанных файлов в едином **ZIP-архиве**.
- **SEO-архитектура для топов Google и Яндекс**:
  - Мультиязычность: русская (`/ru`) и английская (`/en`) версии с тегами `hreflang` и каноническими ссылками.
  - Кластеры посадочных страниц под высокочастотные интенты:
    - `/ru/szhat-jpeg` (Сжать JPEG онлайн)
    - `/ru/szhat-png` (Сжать PNG с сохранением прозрачности)
    - `/ru/szhat-webp` (Сжать WebP)
    - `/ru/konvertirovat-png-v-webp` (Конвертировать PNG в WebP)
    - `/ru/konvertirovat-jpg-v-webp` (Конвертировать JPG в WebP)
    - `/ru/szhat-foto-do-100-kb` (Сжать фото до 100 КБ для Госуслуг и виз)
    - `/ru/izmenit-razmer-foto` (Изменить размер фото в пикселях)
  - **Раздел документации и базы знаний (`/docs`)**:
    - 5 глубоких практических руководств.
    - Встроенные CTA-виджеты.
    - Плотная перелинковка со всеми инструментами.
  - **Микроразметка Schema.org (JSON-LD)**:
    - `SoftwareApplication` / `WebApplication`
    - `FAQPage` (для сниппетов вопросов-ответов в выдаче)
    - `HowTo` (пошаговые руководства)
    - `BreadcrumbList` (навигационные цепочки)
  - Автоматическая генерация `sitemap.xml` и `robots.txt`.

## 💻 Локальный запуск

1. Установите зависимости (если еще не установлены):
   ```bash
   npm install
   ```

2. Запустите сервер разработки:
   ```bash
   npm run dev
   ```

3. Откройте в браузере: [http://localhost:3000](http://localhost:3000)

4. Для проверки продакшен-сборки:
   ```bash
   npm run build
   npm run start
   ```

## 🚢 Деплой на GitHub и Vercel

### Шаг 1: Инициализация репозитория Git и отправка на GitHub

Выполните в терминале в папке проекта:

```bash
git init
git add .
git commit -m "feat: initial release of compress-photo client-side service"
git branch -M main
```

Создайте новый пустой репозиторий на [GitHub](https://github.com/new) (например, `compress-photo`) и привяжите его:

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/compress-photo.git
git push -u origin main
```

### Шаг 2: Деплой на Vercel

1. Перейдите на [vercel.com](https://vercel.com) и войдите через свой GitHub аккаунт.
2. Нажмите кнопку **«Add New...» → «Project»**.
3. Выберите ваш репозиторий `compress-photo` из списка и нажмите **«Import»**.
4. Vercel автоматически определит Next.js. Оставьте настройки по умолчанию и нажмите **«Deploy»**.
5. Через 1 минуту ваш сервис будет запущен на быстром глобальном CDN с бесплатным SSL-сертификатом!

### Шаг 3: Подключение своего домена (по желанию)

В панели Vercel перейдите в **Settings → Domains** и добавьте свой домен (например, `compress-photo.online` или `szhat-foto.ru`). Vercel предоставит DNS-записи (A и CNAME), которые нужно указать у вашего регистратора доменов.
